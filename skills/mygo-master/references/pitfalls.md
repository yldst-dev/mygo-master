# 함정 모음

실제로 겪었거나 v0.7.4 소스에서 확인한 것만 적었다. 증상으로 찾는다. 새 버전에서는 고쳐졌을 수 있으므로, 우회하기 전에 해당 버전의 소스에서 원인이 그대로인지 확인한다.

## 움직임

| 증상 | 원인 | 해결 |
|---|---|---|
| 테마 전환 때 어떤 요소만 멈춰 있다가 끝에 한 번에 바뀐다 | `AnimateColor` 와 `Transition{Colors}` 는 목표색이 바뀌면 진행도를 0으로 되돌린다. 목표색이 프레임마다 바뀌면 진행하지 못한다 | 스칼라를 애니메이션하고 `Mix`, `Alpha` 로 현재 팔레트에서 계산한다 |
| 알약이 선택된 항목의 글자를 가린다 | `Absolute` 자식은 흐름 안 자식보다 위에 칠해진다 | 부모의 `Draw` 에 그린다 |
| 알약이 도착하기 전에 글자가 안 보인다 | 선택이 바뀌는 순간 글자색이 먼저 바뀐다 | 글자색을 알약과 겹친 정도에서 계산한다 |
| 숫자 굴림이 이웃 글자와 겹친다 | 굴림은 위아래로 글자 높이의 0.6만큼 벗어난다. `Text` 의 `Clip` 은 자기 글자를 자르지 않는다 | 부모에 `ClipY` 를 건다 |
| `Enter` 가 재생되지 않는다 | 요소가 새로 생기고 부모는 이전 프레임에 이미 있어야 재생된다. 키가 바뀌면 그 아래 요소의 부모도 새것이다 | 키를 준 요소 자신에 `Transition` 을 건다 |
| 처음 뜰 때 `Enter` 가 재생되지 않는다 | 위와 같은 이유로 화면 전체가 한꺼번에 뜰 때는 재생되지 않는다. 의도된 동작이다 | 첫 화면 연출이 꼭 필요하면 `AnimateTo` 나 `Timeline` 을 쓴다 |
| `Exit` 가 재생되지 않고 뚝 사라진다 | 사라질 때 부모가 그 프레임에 빌드되어야 한다 | `ui.Overlay` 는 항상 부르고 안에서 조건을 건다. 조건부 형제에는 `c.Key` 를 준다 |
| 메뉴에서 다른 메뉴로 바로 넘어가면 옛 패널이 잘린다 | 두 패널이 같은 ID를 쓴다 | 패널마다 `c.Key(open)` 을 준다 |
| 엉뚱한 요소가 상태를 잃거나 얻는다 | `c.Key` 가 소비되지 않고 다음 요소로 넘어갔다 | 키를 준 요소를 만들지 않을 경로에서는 키를 주지 않는다 |
| 페이지 전환 첫 프레임이 비어 보인다 | `Enter` 의 `Opacity` 기본값은 0이다 | 0.35처럼 살짝 보이는 값에서 시작한다 |
| 말풍선이 커서 아래로 오면 깜빡인다 | 호버 대상의 바깥에 있는 말풍선이 호버를 빼앗아 사라지고, 다시 생기기를 반복한다. 호버 대상의 자식이면 일어나지 않는다 | 말풍선에 `IgnoreInput(true)`. `PassThrough` 는 자식에 물려지지 않는다 |
| 위까지 솟는 막대의 말풍선이 제목이나 버튼을 가린다 | 좌우만 가뒀다 | 말풍선 높이만큼 위쪽도 가둔다 |
| 끝까지 스크롤한 상태에서 행을 지우면 위 행들이 튄다 | `Exit` 복사본은 자리를 차지하지 않아 내용 높이가 바로 줄고 스크롤 위치가 잘린다 | 바깥 열의 `MinHeight` 를 스프링으로 줄인다 |
| 애니메이션이 끝났는데 프레임이 더 돈다 | 스프링 꼬리다. 240ms 스프링도 프레임은 600ms 가까이 돌 수 있다 | 정상이다. 끝난 뒤 `FramePending` 이 false면 된다 |
| 말풍선 글자가 바뀔 때 흐리게 겹친다 | 전환이 길다 | 말풍선은 숫자 120ms, 크기와 위치 180ms |
| 말풍선이 카드 밖으로 나간다 | 고정 여유값은 긴 글자에서 모자란다 | `c.MeasureText` 로 재서 가둔다 |
| 사라지던 요소가 다시 나타날 때 처음 자리에서 뛴다 | 원래는 복사본 자리에서 돌아온다. 키가 바뀌면 다른 요소가 된다 | 같은 키를 유지한다 |
| 배지 폭이 바뀔 때 옆 글자가 뛴다 | 전환은 그 요소만 움직인다 | 이웃에도 `Transition{Position}` 을 건다 |
| 호버 페이드가 시작할 때 멈칫하다 끝에 한 번에 바뀐다 | 플래그 없는 `ElementTransition` 은 색까지 전환한다. 스칼라로 프레임마다 바뀌는 배경과 함께 걸면 진행도가 계속 0으로 돌아간다 | 움직이는 요소의 전환에는 `Position`, `Size` 만 명시한다 |
| 전환에서 위치만 끄려고 했는데 전부 움직인다 | `Position`, `Size`, `Colors` 를 모두 비우면 셋 다 애니메이션된다 | 원하는 항목을 하나 이상 명시한다 |
| `Keyframes` 가 앱을 켜자마자 재생된다 | 첫 빌드에 재생된다 | `Run` 이 0이면 걸지 않는다 |
| `ui.List` 행이 드나들 때 움직이지 않는다 | 목록이 행을 직접 배치한다 | 움직임이 필요하면 `Column` 과 `Key` 를 쓴다 |
| 호버된 조각과 흐려진 옆 조각이 헷갈린다 | 흐림이 약하다 | 흐림을 80%로 올리고 크기로도 구분한다 |

## 입력과 포커스

| 증상 | 원인 | 해결 |
|---|---|---|
| Esc로 메뉴를 닫아도 포커스가 버튼으로 돌아오지 않는다 | 오버레이 안에서 `AutoFocus` 를 부르면 열기 전에 포커스가 옮겨져 돌려줄 대상이 잘못 기록된다 | `ui.Overlay` 가 돌아온 뒤에 부른다 |
| 메뉴에서 호버 행과 키보드 행이 함께 강조된다 | 포인터가 머물러 있으면 계속 호버로 판정된다 | 포인터가 새 행에 들어올 때만 포커스를 옮기고, 강조는 `FocusVisible` 또는 포커스와 호버가 함께일 때만 한다 |
| Tab으로 그래프를 벗어나도 말풍선이 남는다 | `chart.Select` 는 포인터가 떠날 때만 선택을 지운다 | `!area.Hovered() && !area.Focused()` 면 지운다 |
| 메뉴에 가려진 도넛 조각이 반응한다 | `PointerPosition` 은 위에 덮인 요소를 보지 않는다 | `Hovered` 와 함께 확인한다 |
| 그래프를 Tab으로 돌면 포커스 링이 네모다 | 링은 요소의 `Radius` 를 따른다 | 그래프 영역에 `Radius` 를 준다 |
| 호버 값이 키보드로는 안 보인다 | 호버에만 묶었다 | `FocusVisible` 도 같은 강조로 묶는다 |
| 시험 창에서 키보드 동작이 전혀 안 먹는다 | 창이 키 윈도우가 아니면 `Focused` 가 false다 | `windows` 의 `focused` 를 확인한다 |
| 한글을 쓰고 Enter를 두 번 눌러야 제출된다 | 조합 중인 키는 입력기 몫이다. 공식 문서와 `internal/darwin/surface.go` 를 보면 조합 중 Enter는 앱에 오지 않고 입력기의 줄바꿈 명령도 버려진다. 소스 기준이며 실제 입력기로는 아직 확인하지 못했다 | Enter로 제출하는 입력칸은 실제 한글 입력기로 확인한다. 우회가 필요하면 `HandleInput` 에서 조합이 끝난 직후의 `InputKeyUp` 을 Enter로 받고, 끝 글자가 한글일 때만 제출한다. 일본어와 중국어의 후보 확정은 건드리지 않는다 |
| 더블클릭하면 다음 행까지 지워진다 | 행이 빠지면서 다음 행의 버튼이 포인터 아래로 온다 | 500ms 안의 반복 삭제를 무시한다. 되돌리기를 주면 더 좋다 |
| 키보드로 지운 뒤 타자가 아무 데도 안 간다 | 포커스를 가진 요소가 사라졌다 | 지운 버튼에 포커스가 있었으면 입력칸으로 돌려준다 |
| 내장 말풍선이 늦게 뜬다 | `Tooltip` 은 0.6초 뒤에 뜨고 움직임이 없다 | 값을 읽는 곳은 `chart.Anchor` 로 직접 그린다 |
| 내장 메뉴와 검색 칸에 움직임을 넣을 수 없다 | `PopoverMenuButton` 패널과 `SearchField` 지우기 버튼은 공개된 자리가 없다 | 베이스로 다시 짠다. `TextInputBase` 로 바꾸면 검색 필드 역할이 일반 입력칸으로 바뀌므로 보고한다 |

## 테스트

| 증상 | 원인 | 해결 |
|---|---|---|
| `go test` 가 CPU 0%로 몇 분씩 멈춘다 | `mygo.Theme.SetSource` 처럼 메인 스레드로 넘기는 호출은 메인 루프가 없는 테스트에서 영원히 기다린다 | 함수로 주입하고, `-timeout` 으로 스택을 본다 |
| 크기 검사가 버튼이 아니라 글자를 잰다 | `Find` 는 그 글자를 보여 주거나 그 `Label` 을 단 첫 요소를 준다. 버튼에 `Label` 이 없거나 같은 글자가 앞에 있으면 다른 상자가 잡힌다 | 누를 것마다 겹치지 않는 `Label` 을 준다([design.md](design.md#크기를-테스트로-지킨다)) |
| 변이가 모두 잡혔다고 나오는데 믿을 수 없다 | 컴파일 실패도 실패로 잡힌다 | `scripts/mutate.py` 는 `BROKEN` 으로 따로 보여 준다 |
| 변이를 넣었는데 테스트가 통과한다 | 테스트 이름이 틀리면 아무것도 돌지 않고 통과한다 | 같은 도구가 `BROKEN` 으로 보여 준다 |
| 테스트가 호버 중 프레임을 계속 요청한다 | 애니메이션이 끝나지 않거나 뷰가 값을 계속 바꾼다 | `FramePending` 을 확인하고 쉬는 값을 고정한다 |
| Tester 패닉: 같은 키 | 같은 부모 아래 같은 키가 둘이다 | 키를 고유하게 준다 |
| 눌렀다 뗐는데 `tt.Find` 의 폭이 줄어든 채로 남아 있다 | 포즈 프레임은 칠하기만 하므로 `Find` 는 마지막 빌드의 값을 준다. 실제로는 돌아왔다 | 픽셀로 비교하거나 `tt.Frame` 뒤에 읽는다 |
| 소스를 읽는 테스트가 변이를 놓친다 | `-overlay` 는 컴파일에만 적용되고 `os.ReadFile` 은 실제 파일을 읽는다 | 임시 복사본을 실제로 고쳐 확인한다 |
| 픽셀을 읽었는데 값이 조금 다르다 | 끝나기 전에 읽었다 | `tt.Advance(time.Second)` 뒤에 읽는다 |
| 값 검사에 실패한 줄 알았는데 글자 위치가 다르다 | 위치 전환이 진행 중이면 `Find` 도 중간값을 준다 | 끝까지 보낸 뒤 비교한다 |

## 실제 창과 환경

| 증상 | 원인 | 해결 |
|---|---|---|
| 소켓에서 `bind: invalid argument` | 유닉스 소켓 경로 길이 제한 | 작업 폴더 기준 짧은 상대 경로를 쓴다. `drive.py` 가 그렇게 한다 |
| 실행 직후 `idle: no_window` | 창이 아직 없다 | 다시 시도한다. `Client` 가 처리한다 |
| 호버 후 바로 읽었는데 반응이 없다 | `idle` 이 애니메이션 시작 전에 돌아왔다 | 잠깐 기다린다. `settle` 이 처리한다 |
| 말풍선이 두 개다 | 실제 마우스가 시험 창 위에 있다 | 마우스를 치우고 다시 돌린다 |
| 문서대로 썼는데 컴파일이 안 된다 | 웹사이트나 `main` 문서는 릴리스보다 앞서 있을 수 있다. 또는 기억 속 API가 낡았다 | 모듈 캐시의 해당 버전 문서와 `go doc` 을 본다 |
| 시험 앱을 돌린 뒤 데이터가 남았다 | 시험 빌드도 `~/Library/Application Support/<실행 파일 이름>` 에 저장한다 | 끝나면 지운다 |
| 저장 파일이 깨지면 앱이 창 없이 죽는다 | 시작 단계의 `log.Fatal` 은 사용자에게 보이지 않는다 | 이유를 보여 주는 화면을 띄우고 파일을 덮어쓰지 않는다 |
| 프로젝트에 큰 실행 파일이 생겼다 | 패키지가 하나인 모듈에서 `go build ./...` | `-o /dev/null` 을 쓰고 생긴 파일은 지운다 |
| `go tool mygo dev` 를 멈춰도 앱이 남는다 | 자식 프로세스가 따로 돈다 | `pgrep` 으로 찾아 끝낸다 |
| `mygo build` 가 `codesign ...: signal: bus error` 로 실패한다 | 앱 이름에 한글 같은 비 ASCII 글자가 있으면 실행 파일 이름에도 들어가고, macOS 27.2의 `codesign --deep` 이 그 파일에서 죽는다. 직접 재현했다. 실행 파일 이름만 따로 정하는 설정은 찾지 못했다 | `mygo.json` 의 `name` 은 영문으로 하고 창 제목과 화면 글자만 한글로 쓴다. 충돌 보고서가 `~/Library/Logs/DiagnosticReports` 에 남으니 시험 후 지운다 |
| 앱을 두 개 띄우면 저장 내용이 서로 덮인다 | 프로세스마다 메모리 상태를 따로 들고 파일을 통째로 쓴다 | 파일에 저장하는 앱은 `mygo.App.RequestSingleInstanceLock` 을 검토한다(`docs/app.md`) |
| 앱 아이콘이 보라색 그라데이션이다 | `resources/icon.png` 의 기본 아이콘이다 | 요청자에게 보일 앱이면 바꾸거나 제안한다 |
| 오른쪽 클릭 메뉴와 기본 메뉴 글자가 영어로 나온다 | v0.7.4의 `locales` 에는 `ja`, `zh-Hans`, `zh-Hant` 만 있다 | 알고 넘어가거나 `docs/i18n.md` 를 보고 직접 넣는다. 보고에 적는다 |
| `mygo init .` 이 거부된다 | `.git` 이 있어도 빈 폴더가 아니다 | 하위 폴더에 만든다 |
| 재실행 직후 창 크기가 다르게 읽히거나 접근성 조회가 막힌다 | 원인을 밝히지 못했다. 한 번 겪었고 약 14분 뒤 정상으로 읽혔다 | 바로 판단하지 말고 다시 읽어 본 뒤, 남아 있으면 보고한다 |
| `echo =====` 가 zsh에서 실패한다 | zsh의 `=` 확장 | 따옴표로 감싼다 |
| kill-ai-slop 스캐너가 0개 파일을 읽었다고 나온다 | 웹 파일 중심이라 Go를 읽지 못한다 | 항목표를 보고 직접 점검한다 |
